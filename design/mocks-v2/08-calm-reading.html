README.md

ether-core

Ether is a self-hosted home for private Git repositories, issues and pull requests. It runs inside your Tailscale network, so only people you invite can reach it. Set it up with the four commands below.

bun install
bun run build
bun run ether create-admin <you> --password '...'
bun run start
  • Create the first account with create-admin. Everyone else joins through a one-time invite link.
  • Git clients connect over HTTPS and authenticate with a personal access token.
  • Repositories are stored on the server's local disk. Back them up with the backup command.
