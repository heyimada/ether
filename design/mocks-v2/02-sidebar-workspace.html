README.md

ether-core

Ether core runs the server, the web client and the git transport in one process. It serves repositories over HTTPS and is meant to run only inside your tailnet, for a small group of people you trust.

bun install
bun run build
bun run ether create-admin <you> --password '...'
bun run start
  • Accounts are created from one-time invite links that an admin issues.
  • Every repository is private. Add collaborators with Read or Write access.
  • Git authenticates with a personal access token, never your account password.
