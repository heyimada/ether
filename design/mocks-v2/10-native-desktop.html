README.md

ether-core

Ether core is the server, the web client and the git transport for a self-hosted code host. It runs inside your tailnet, keeps repositories on your own disk and serves them over HTTPS with personal access tokens. Start here to build it and create the first admin account.

bun install
bun run build
bun run ether create-admin <you> --password '...'
bun run start
  • Repositories are private, and you share them with collaborators as Read or Write.
  • People join through one-time invite links that an admin creates.
  • Git works over HTTPS only. Use a personal access token, not your account password.
