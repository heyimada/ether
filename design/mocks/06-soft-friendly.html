ether-core

Ether keeps a handful of private repositories on hardware you own. This package holds the server, the git transport and the web interface, so one process serves all of them.

Run it locally

# install, then start with a seeded admin account
pnpm install
pnpm dev --seed-admin

What is in here

  • src/ the Hono server, git smart HTTP and the sync engine.
  • e2e/ Playwright flows for invites, pushes and merges.
  • drizzle/ the SQLite schema and ordered migrations.
