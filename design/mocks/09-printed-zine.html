ether-core

Ether is a small, invite-only place to keep git repositories for a handful of friends. This repository holds the server and the web client.

Running locally

You need Bun, and a Tailscale node for the tailnet URL to resolve. Then:

shellbash
$ bun install
$ bun run dev
# first run creates data/ and the sqlite file

Notes

  • The first account is created with bun run scripts/make-admin.ts.
  • Invites are minted from Settings → People and expire after seven days.
  • Repositories live on disk under data/repos, one bare repo each.

Clone

https://pc.tail576a27.ts.net/admin/ether-core.git

Use your Ether username and an access token when git asks.
