README.md Rendered

ether-core

Ether keeps a handful of private repositories on hardware you own. This package holds the server, the git transport and the web interface, so one process serves all of them.

Run locally

# install and start with a seeded admin account
pnpm install
pnpm dev --seed-admin

What is here

  • src/Hono server, git smart HTTP and the sync engine.
  • e2e/Playwright flows for invite, push and merge.
  • drizzle/SQLite schema and ordered migrations.
