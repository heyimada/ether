README.md

ether-core

Ether is a small, self-hosted git host for a handful of friends. Repositories live on disk as bare git repos. This package holds the HTTP server, the web UI and the invite flow that gates signup.

Quick start

# needs Node 22 and pnpm
pnpm install
pnpm db:migrate
pnpm dev     # http://localhost:4000
  • Invite-only registration with single-use tokens that expire after 7 days
  • Smart HTTP git transport, so friends clone with a login and no SSH keys
  • One process, one SQLite file, no public ports
