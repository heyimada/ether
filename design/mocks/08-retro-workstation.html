README.md

ether-core

Ether is a small, self-hosted git host for a handful of friends. Repositories live on disk as bare git repos; metadata lives in SQLite; access is invite-only and reachable only over the tailnet.

# clone over the tailnet, then build and run locally
git clone https://pc.tail576a27.ts.net/admin/ether-core.git
bun install && bun run dev
  • Smart HTTP push and fetch, no SSH keys to manage
  • Issues, pull requests, and a diff view with split mode
  • Migrations via drizzle-kit, tests via Playwright
