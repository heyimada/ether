README.md

ether-core

Ether is a small, invite-only place to keep git repositories for a handful of friends. This repository holds the server and the web client.

Running it locally

You need Bun. For the tailnet URL to resolve you also need a Tailscale node on the machine. Then:

Shell 
$ bun install
$ bun run dev
# first run creates data/ and the sqlite file

Good to know

  • The first account is created with bun run scripts/make-admin.ts.
  • Invites are minted in Settings, then People, and they expire after seven days.
  • Repositories live on disk under data/repos, one bare repo each.

Clone this repo

Copy the HTTPS address, then paste it into git. Git will ask for your Ether username and an access token.

https://ether.example.ts.net/admin/ether-core.git
