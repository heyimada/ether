README.md

ether-core

Ether is a small, invite-only place to keep our git repositories. It runs on one machine behind Tailscale, so the clone URL only resolves inside the tailnet.

First run

Install the workspace and start the dev server. The database file lives in data/ and is created on first boot.

# from the repo root
bun install
bun run db:migrate
bun run dev

Notes

  • Registration is closed by default. Admins issue invite codes from Settings.
  • Pushes authenticate with a personal access token, never a password.
  • Run bun run e2e before merging anything that touches auth.
